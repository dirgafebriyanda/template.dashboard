# Template Dashboard

A modern Dashboard UI template built with HTML and Tailwind CSS.

## Preview

Live Demo: https://template-dashboard-two-omega.vercel.app/

## Features

* Login form
* Register form
* Forgot password form
* Reset password form
* Dashboard
* 404 Page Not found
* Responsive design
* Tailwind CSS
* Clean and modern UI
* Easy customization

## Getting Started

### Clone Repository

```bash
git clone https://github.com/dirgafebriyanda/template.dashboard.git
cd template.dashboard
npm install
```

### Open Project

Open `index.html` directly in your browser.

Or run a local server:

```bash
npm run dev
```

## Customization

You can easily customize:

* Colors
* Fonts
* Form fields
* Animations
* Layout
